## 👟 Premium Shoes Web Page

A stylish and non-responsive product showcase webpage for premium shoes. This project displays different categories of men's footwear with pricing, discounts, and add to cart buttons.

---

## ✨ Features

- 🖼️ Modern product card layout  
- 💸 Discounted price with original price strike through  
- 🛒 Add to Cart buttons  
- 🎨 Clean UI design  

---

## 🚀 Technologies Used

- 🌐 HTML5  
- 🎨 Tailwind CSS  

---

## 🎯 Purpose

This project is created for:

- Practicing frontend development  
- Learning layout design  
- Building UI components  

---

## 📌 Future Improvements

- Add JavaScript for cart functionality  
- Make it responsive
